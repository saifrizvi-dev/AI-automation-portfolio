# AI Automation Portfolio

AI automation workflows built with n8n and Ollama.

## Projects

### 1. AI Weather Email — Daily Automation
Automated daily weather email using OpenWeatherMap API and Ollama AI. Sends a naturally written weather update every morning.

### 2. AI Customer Email Reply Generator
Form-based workflow that takes a customer email, generates a professional AI reply using Ollama, and sends it automatically.

### 3. Google Sheets AI Response System
Reads customer queries from Google Sheets, generates AI responses using Ollama, and writes them back to the sheet automatically.

## Stack
- n8n (workflow automation)
- Ollama + llama3.2 (local AI)
- Google Sheets API
- SMTP Email
